E. FILE TXT — informasi numerik untuk penulisan jurnal
================================================================================

[22] jurnal_info_stage1.txt
     Dihasilkan  : stage1_forecaster.py
     Isi         :
       - Statistik preprocessing (jumlah baris per hari setelah warmup drop)
       - Rentang normalisasi per parameter (min/max dari scaler)
       - Hyperparameter TCN (epoch, batch, lr, weight decay, gradient clip)
       - Arsitektur TCN (7 residual block, dilation, n_ch, kernel)
       - Hasil training: MSE epoch 1, MSE epoch akhir, persentase penurunan
       - Hasil evaluasi test: MSE / RMSE / MAE
       - Selisih MSE train-test (indikator generalisasi)
       - Tabel sequence lengkap: No | Tanggal | Window Input → Target | Set
     Jurnal      : Data numerik untuk Bab Hasil & Pembahasan — Stage 1

[23] jurnal_info_stage2.txt
     Dihasilkan  : stage2_classifier.py
     Isi         :
       - Distribusi label (jumlah hari per kelas + tanggal masing-masing)
       - Hyperparameter MLP (epoch, batch, lr, weight decay)
       - Arsitektur MLP (84→256→128→64→3, aktivasi, dropout)
       - Class weights (0.5, 2.5, 4.0)
       - Hasil training: CE epoch 1, CE epoch akhir, Accuracy epoch akhir
       - Confusion matrix training (3×3 dalam teks)
       - Confusion matrix testing (3×3 dalam teks)
       - Classification report: precision, recall, F1 per kelas
       - CE loss pada test set + selisih train-test CE
     Jurnal      : Data numerik untuk Bab Hasil & Pembahasan — Stage 2

[24] jurnal_informasi_lengkap.txt
     Dihasilkan  : stage3_inference.py
     Isi         :
       BAGIAN A — Dataset & Normalisasi:
         - Jumlah hari total, pembagian train/test
         - Rentang normalisasi per parameter (dari scaler Stage 1)
         - Distribusi label + tanggal per kelas
         - Tabel status kesehatan per hari (Day, Tanggal, Status, Set)
       BAGIAN B — Training Inference:
         - MSE / RMSE / MAE perbandingan prediksi vs ground truth
         - Status kesehatan prediksi Day 11 (kode + label + confidence)
         - Template caption untuk paragraf jurnal (Para 224)
       BAGIAN C — Testing Inference:
         - Status kesehatan prediksi Day 14
         - Confidence dan probabilitas per kelas
         - Template caption untuk gambar dan paragraf jurnal
       BAGIAN D — Daftar file lengkap dengan nomor Gambar jurnal
     Jurnal      : Referensi utama untuk SEMUA data angka dalam jurnal
